# Obsidian + AI: 3 способа подключить агента к базе знаний

Автор: Антон Морев (канал про AI с практическим уклоном).

## 3 способа

### 1. Obsidian CLI
- Obsidian должен быть запущен на том же компе
- Агент тоже локально
- Жёсткая привязка, неудобно

### 2. Прямой доступ к папке .md
- PDF / OpenCode / Claude Code указываешь на папку с vault
- Работает, но только локально
- Агент не изолирован — может поломать файлы

### 3. MCP-сервер + self-hosted LiveSync (рекомендуемый)
- **VPS:** Obsidian vault + MCP-сервер + агент (PikaCL / OpenCode / Hermes)
- **Клиент:** телефон/десктоп с Obsidian + LiveSync
- Синхронизация в реальном времени
- Агент доступен 24/7, можно подключить к Telegram
- Изоляция: агент на сервере, не на рабочем компе

## Архитектура (как у нас)

```
VPS ─── Hermes ──MCP──▶ Obsidian vault
  │                         │
  └── Telegram ◀────────── LiveSync ↔ телефон
```

**Мы уже на варианте №3 через Hermes.**

## Инструменты из видео

- **PikaCL** — легковесная альтернатива OpenCode (10 MB RAM, работает даже на старых телефонах)
- **Obsidian LiveSync** — self-hosted синхронизация (ставится на VPS)
- **MCP-сервер** — прослойка между агентом и vault (поддерживает авторизацию)
- **eworsoft.ru** — его провайдер доступа к китайским моделям

## Мысли для нас

- У нас уже MCP-сервер для Obsidian? Если нет — стоит добавить
- PikaCL заценить — легче OpenCode, для экспериментов норм
- LiveSync у нас и так через Git, но MCP даёт агенту структурированный доступ
