# AGENTS.md — Knowledge Vault

> Личная база знаний Полякова Алексея. Все AI-агенты ОБЯЗАНЫ читать этот файл перед ответом.

## Правила работы с vault

1. **Перед ответом на любой вопрос** — поищи релевантные заметки в vault через `search_files` или `search_my_vault`
2. **Нашёл конфликт** — сообщи о противоречии, не перезаписывай молча
3. **Новая информация** → `inbox/` (не в корень, не в проекты)
4. **Обработанный inbox** → переместить в нужный раздел, обновить индекс
5. **Формат ссылок:** `[[path/file|Label]]` — Obsidian wikilinks

## Статусы заметок (в frontmatter или первой строке)

- `status: active` — актуально
- `status: draft` — черновик
- `status: archived` — архив
- `as_of: YYYY-MM-DD` — дата актуальности
