# Claudexor + ru-marketplace-mcp

> 26.07.2026 — два репозитория от русских разработчиков

## ru-marketplace-mcp (24 ⭐)

MCP-сервер для Wildberries, Ozon, Яндекс Маркет, Детский мир. 22 инструмента: поиск товаров, цены, остатки, отзывы, реквизиты продавцов.

- `compare_prices` — параллельный опрос площадок
- Только чтение, без API-ключей
- Ozon может потребовать Chrome при антиботе

**GitHub:** [ru-marketplace-mcp](https://github.com/ru-marketplace-mcp)

## Claudexor (316 ⭐)

Локальная панель управления для Claude Code, Codex, Cursor CLI, OpenCode.

- Общий контекст между агентами
- Параллельные решения с независимой проверкой
- Делегирование подзадач
- Контроль квот Claude/Codex
- CLI для macOS/Linux + macOS-приложение

**GitHub:** [Claudexor](https://github.com/Claudexor)

## Вердикт

- **ru-marketplace-mcp** — полезно для мониторинга цен РФ. Не приоритет.
- **Claudexor** — идея оркестрации агентов близка к нашей Hermes-архитектуре. Не под Hermes (заточен под Claude Code/Codex). Изучить архитектуру.
