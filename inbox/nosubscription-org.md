# NoSubscription.org

> 26.07.2026 — каталог софта без подписок

## Что это

[NoSubscription.org](http://nosubscription.org) — каталог программ с единоразовой покупкой. Альтернатива SaaS-подпискам.

## Категории

Софт разбит по категориям, платформам, цене и лицензии. Можно найти альтернативы популярным subscription-сервисам.

## Для нас

Полезно при выборе инструментов для Hermes-инфраструктуры — ищем one-time purchase вместо monthly subscription где возможно.
