# Положение об идентификации опасностей и определению уровня профессиональных рисков

## 1-2. Общие положения и область применения

- Цель: создание процедуры управления профессиональными рисками
- Обязательно для **всех** структурных подразделений, администрации и филиалов

### Цели (п. 2.1)
- Предотвращение травматизма и профзаболеваний
- Объективная информация о состоянии производственной безопасности
- Эффективное управление профессиональными рисками
- Обоснованные рекомендации по снижению рисков
- Оценка рисков с учётом существующих мер управления

## 4. Термины

| Термин | Определение |
|--------|------------|
| **Профессиональный риск** | Вероятность вреда здоровью × тяжесть последствий |
| **Управление рисками** | Выявление → оценка → снижение → мониторинг |
| **Приемлемый риск** | Не требует дополнительных мер |
| **Допустимый риск** | Снижен до уровня, допустимого организацией |
| **Неприемлемый риск** | Требует выработки новых мер управления |
| **Идентификация опасности** | Распознавание и описание опасности |
| **Опасность** | Потенциальный источник вреда |

## 5. Организация оценки рисков

### Кто возглавляет
**Главный инженер — первый заместитель генерального директора**

### Рабочие группы

**Администрация Общества:**
- Главный инженер — 1-й зам. ген. директора
- Зам. главного инженера по ОТ, ПБ и ПБ
- Начальник ООТ
- Начальник службы ПБ
- Руководители структурных подразделений

**Филиалы:**
- Главный инженер филиала
- Руководитель подразделения по ПБ (или специалист ОТ)
- Руководители подразделений
- Иные специалисты

### Ознакомление
После оценки → ознакомление работников с результатами → **подпись в карте ОПР**.

## 6. Идентификация опасностей

### Методика
В соответствии с Приказом Минтруда № 36.

### Исходные данные
- Виды работ, здания, сооружения, территории
- Оборудование, технологические процессы
- Инструменты, сырьё, материалы
- НПА с требованиями охраны труда
- Результаты СОУТ
- Результаты производственного контроля
- Предписания надзорных органов
- Материалы расследования происшествий
- Обратная связь от работников

## 7. Определение уровня риска

### Метод: «Матрица последствий и вероятностей»
На основе Приказа Минтруда № 926.

### Тяжесть последствий (5 категорий)

| Уровень | Описание |
|:-------:|----------|
| **Незначительный** | Мелкие травмы, не влияющие на трудоспособность |
| **Малый** | Травмы с потерей трудоспособности до 15 дней |
| **Средний** | Тяжёлая травма, потеря >15 дней, необратимый ущерб |
| **Большой** | 1–3 случая инвалидности или летального исхода |
| **Очень большой** | >3 летальных исходов |

### Вероятность (5 категорий)

| Уровень | Описание |
|:-------:|----------|
| **Очень низкая** | Практически никогда |
| **Низкая** | Маловероятно |
| **Средняя** | ~50% |
| **Высокая** | Скорее всего произойдёт |
| **Очень высокая** | Почти обязательно |

### Расчёт
```
Уровень риска = Тяжесть × Вероятность
```

### Итоговая классификация (матрица 5×5)

| Уровень риска | Действие |
|:-------------:|----------|
| **Низкий** | Поддержание существующих мер |
| **Умеренный** | Мониторинг, возможна доработка мер |
| **Высокий** | Требуется разработка дополнительных мер |
| **Недопустимый** | Немедленная остановка работ, срочные меры |

## 8. Меры по снижению рисков (иерархия)

Приоритетность мер (от высшего к низшему):

1. **Исключение** опасной работы (процедуры, процесса, сырья, оборудования)
2. **Замена** на менее опасное
3. **Инженерные (технические)** методы — ограждения, блокировки, вентиляция
4. **Административные** методы — инструкции, обучение, знаки, допуски
5. **СИЗ** — последний рубеж защиты

### Принципы
- Использовать **сочетание** разных мер, не полагаться на одну
- Превентивные меры: наблюдение за здоровьем, информирование, обучение
- **Непрерывный мониторинг** эффективности (в т.ч. через АПК I-IV уровней)
- При неэффективности → корректировка

## 9. Документирование

### Карта ОПР
- На каждое рабочее место — **карта ОПР** (Приложение 3)
- Вносится в **ИУС ПБ** (раздел СОУТ-документы оценки рисков)
- Согласование членами рабочей группы
- Ознакомление работника под подпись

### План мероприятий (Приложение 5)
- Формируется через СЭД
- Консолидирует все меры управления рисками
- Утверждается:
  - Администрация → главный инженер — 1-й зам. ген. директора
  - Филиалы → главный инженер филиала
