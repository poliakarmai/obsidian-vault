## 1. Общие положения

1.1. Положение разработано для единого подхода к проведению поведенческого аудита безопасности (ПАБ).

1.2. Требования распространяются на **все филиалы** Общества.

1.3. **Не распространяется** на административные отделы, работники которых не выполняют работы на производственных объектах.

1.4. Определяет процедуру проведения ПАБ.

1.5. **ПАБ** — аудит, основанный на **наблюдении + беседе** с работником во время выполнения производственного задания.

---

## 2. Цели, задачи и принципы ПАБ

### Ключевое правило
> Если аудитор **только наблюдал без беседы** — это **не ПАБ** (п. 2.2).

### Цели
- Предотвращение травматизма, аварий, пожаров, ДТП, профзаболеваний
- Объективная информация о состоянии производственной безопасности
- Повышение информированности персонала
- Повышение культуры производственной безопасности

### Задачи
- Определение сильных/слабых сторон ЕСУПБ
- Формирование осознанности приоритета безопасности
- Закрепление привычек безопасного выполнения работ
- Мотивация на безопасный труд

### Принципы
- **Регулярность**
- **Отсутствие наказаний** за небезопасные действия
- Идентификация **положительных** аспектов
- Соблюдение мер безопасности при проведении ПАБ
- Недопущение повышения уровня риска

## 3. Требования к процедуре

### Кто проводит
- Только **обученные аудиторы** в рабочее время
- **Не рекомендуется** совмещать с административно-производственным контролем
- Допускается во время профилактических/лидерских визитов

### График
- Формируется ежегодно до **25 декабря**
- Указываются только обученные аудиторы
- Допускаются изменения при обучении новых аудиторов

### Периодичность

| Уровень | Кто | Частота |
|---------|-----|---------|
| Линейный | Мастер, механик участка/службы/цеха | ≥ 4 раза/мес |
| Средний | Начальник участка/цеха/службы, директор, нач. комплекса | ≥ 1 раз/мес |
| Филиал | Руководитель филиала, зам., гл. инженер, ООТ, ПТО, гл. механик, гл. энергетик | ≥ 1 раз/квартал |
| Общество | Ген. директор, гл. инженер, зам. по ОТ, ООТ Общества, гл. механик/энергетик | ≥ 1 раз/6 мес |

### Порядок проведения
Подготовка → Посещение + наблюдение → Беседа → Оформление → Анализ

## 4. Подготовка к ПАБ

Включает:
- Определение объекта аудита с учётом недавних происшествий
- Изучение техпроцесса, правил безопасной эксплуатации
- Ознакомление с рисками и мерами управления
- Рассмотрение документации (стандарты, регламенты, инструкции)
- Рассмотрение методов мотивации к безопасному труду

## 5. Порядок наблюдения

### Процесс
1. Открытое приветствие
2. Наблюдение за ходом работ
3. Анализ увиденного

### 7 категорий наблюдения

| № | Категория | Критериев |
|---|-----------|:---------:|
| 1 | Реакция работника | 7 |
| 2 | Действия работника | 12 |
| 3 | Спецодежда и СИЗ | 5 |
| 4 | Инструмент и оборудование | 4 |
| 5 | Инструкции и правила | 3 |
| 6 | Рабочее место | 3 |
| 7 | Транспорт | 6 |
| **Всего** | | **40** |

### Ключевые моменты наблюдения

**Реакция (10-30 сек):**
- Если работник при виде аудитора надевает СИЗ/меняет позу → знает правила, но не соблюдает
- Важно понять **почему**: личные убеждения, условия, нехватка ресурсов?

**Действия:**
- Оценить позу, защиту от опасностей (движущиеся предметы, вещества, электричество)

**СИЗ:** метод «с головы до ног» — наличие, правильность, состояние

**Инструмент:** соответствие работе, исправность, отсутствие кустарного

**Инструкции:** доступны, актуальны, соблюдаются

**Рабочее место:** захламлённость, скользкий пол, расположение инструментов

**Транспорт:** ремни, состояние водителя, стиль вождения, ПДД, мобильные

## 6. Проведение беседы

### При угрозе жизни
Немедленно остановить работы + оповестить руководство (п. 6.1).

### Правила диалога
- Начинать только когда **безопасно** и удобно работнику
- Уважительный тон, зрительный контакт, открытый язык тела
- Отметить **минимум 1 безопасное действие**
- Открытые вопросы («как», «что», «каким образом»)
- **Не говорить слово «нарушение»**
- Работник **сам** должен идентифицировать опасные действия
- Переводить беседу чтобы работник сам осознал ошибки

### Чего избегать (п. 6.4)
- Назидательный/пренебрежительный тон, обвинения, нравоучения
- Невнимание, отсутствие интереса
- Ответы на свои же вопросы
- Информирование работника об опасностях (он сам должен найти)
- Риторические/наводящие вопросы
- Слово «нарушение»

### Если работник действует безопасно (п. 6.5)
- Описать безопасные действия, отметить усилия
- Спросить как действия снижают риск травмы
- Личное заявление об оценке
- Поблагодарить

### Если опасно (п. 6.6)
- Сначала отметить безопасные аспекты
- Выяснить понимание инструкций
- Спросить о последствиях опасного действия
- Заручиться согласием о необходимости снижения риска
- Обсудить альтернативные безопасные практики
- Договориться о корректирующих действиях
- Поблагодарить

### Самоанализ аудитора (п. 6.7)
- Оказал ли разговор влияние?
- Был ли честный разговор?
- Оценил ли работник степень риска?
- Достигнуто ли ясное соглашение?
- Что сделать лучше в следующий раз?

## 8. Обработка данных и анализ

### Периодичность анализа
Не реже **1 раза в квартал** отделом охраны труда.

### Рассмотрение
На совещаниях по производственной безопасности АПК II, III, IV уровня.

### Ключевые показатели

#### Выполнение графика
```
Г = (Ап / Аз) × 100%
```
- Ап — проведено аудитов
- Аз — запланировано аудитов

#### Неучастие руководителей
```
Nн.р. = (Nн / Nу) × 100%
```
- Nн — не выполнили план
- Nу — общее число руководителей

#### Показатель опасности одного аудита (по категории)
```
Ni = (Ко / (n − Кн)) × 100%
```
- Ко — критериев «Опасно»
- Кн — критериев «Неприменимо»
- n — всего критериев в категории (по таблице 1)

**Таблица 1 — количество критериев по категориям:**

| Категория | n |
|-----------|:-:|
| Реакция работника | 7 |
| Действия работника | 12 |
| Спецодежда и СИЗ | 5 |
| Инструмент и оборудование | 4 |
| Инструкции и правила | 3 |
| Рабочее место | 3 |
| Транспорт | 6 |

#### Общий показатель опасности (No)
```
No = ΣNi / Ai
```
Сумма показателей всех аудитов / количество аудитов.

#### Показатель опасности категории за период (Ni_onl)
```
Ni_onl = Σ(Ni_on) / l
```
Сумма показателей категории по всем аудитам / количество аудитов.

### Визуализация
- **Линейный график** No по кварталам
- **Лепестковая диаграмма** Ni_onl по категориям
- **«Область тревоги»** — на основе происшествий + статистики
- Пересечение области тревоги с графиком → **приоритетные категории**

### Особые случаи
- **Отрицательные Ni_onl** → принимаются = 0
- При отрицательных значениях → расчёт через **коэффициент частоты**:
  ```
  Kчод_i = опасных действий / наблюдений
  ```
